***REMOVED*** UI Components

UI components follow the Atomic Design methodology:

***REMOVED******REMOVED*** Structure

- **Atoms**: Basic building blocks (buttons, inputs, labels)
- **Molecules**: Combinations of atoms (search bars, form groups)
- **Organisms**: Complex UI sections (headers, forms, navigation)
- **Templates**: Page layouts and structural components

***REMOVED******REMOVED*** Usage Guidelines

- Components in this directory should be purely presentational
- They should not contain business logic or feature-specific code
- Props should be well-typed and have sensible defaults
- Use composition over inheritance for component reuse
